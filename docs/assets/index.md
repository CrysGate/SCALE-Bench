# 资产图鉴

每种资产使用一个页面，集中展示不同尺寸（scale）的仿真资产图片、物理属性和抓取姿态数据状态。

## 资产目录

## 抓取数据标准

每种机械臂对每个物体需要 **1024 条抓取姿态数据**。不同尺寸规格分别对应独立的物体资产和抓取数据文件，因此按「尺寸规格 × 机械臂」逐项统计，不能跨规格或机械臂合并凑足数量。

各资产页注明核对日期，按文件中实际可加载的候选数量记录进度。达到数量标准表示数据量达标，任务中的可达性、碰撞与执行结果仍由实际运行验证。
